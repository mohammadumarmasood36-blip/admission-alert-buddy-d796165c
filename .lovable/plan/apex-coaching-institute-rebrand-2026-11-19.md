# Apex Coaching Institute Rebrand

## Goal
Rebrand the public website for Apex Coaching Institute, serving CBSE and UP Board students in classes 9–12, while preserving the existing student, parent, teacher, cashier, staff, fee, notice, exam, attendance, and website-management workflows.

## Work
- Refresh the homepage identity, coaching-focused copy, class/program information, images, navigation, and calls to action without removing existing sections or enquiry/portal access.
- Replace outdated school-only names and claims in public pages, portal sign-in, generated student/fee documents, payment display labels, and install/app metadata; retain existing operational data and feature behavior.
- Keep contact details and institute-specific claims that were not supplied from being newly invented; preserve verified existing contact paths where still applicable.
- Validate the public homepage and mobile layout, confirm portal access remains present, run existing fee regression tests, and check preview build/runtime logs.

## Technical details
- Reuse the existing classroom image and design system; use a consistent Apex wordmark and a new institute mark in public navigation and app branding.
- Preserve existing routes, auth, backend data flows, payment validation, PWA install behavior, and management controls.
